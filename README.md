# Дарья Новикова

## Командные проекты

### [Map of local issues](https://github.com/AndreyV105105105/Map_of_local_issues) · фронтенд

Веб-платформа, на которой жители Ханты-Мансийска могут отмечать
городские проблемы на интерактивной карте и отслеживать обращения

Разрабатывала пользовательский интерфейс: страницы карты и обращений,
детали проблемы, профиль, формы входа и регистрации. Работала
с отображением отметок на карте и интерфейсами для жителей
и должностных лиц

### [WEBB](https://github.com/polisha067/WEBB) · бэкенд

Киноплатформа с каталогом фильмов, подписками, списком просмотра
и пользовательским контентом. В проекте используются Django REST
Framework, FastAPI и Flask

Разрабатывала серверную логику подписок и API, асинхронное взаимодействие
FastAPI с Django, обработку ошибок и фоновые задачи. Работала над
моделями, валидацией и API комментариев, а также тестами для этой
функциональности

### [mini_t1](https://github.com/polisha067/mini_t1) · бэкенд

Система для проведения и оценки хакатонов: организаторы создают
конкурсы и команды, эксперты выставляют баллы, а система формирует
рейтинг

Реализовывала серверные функции для управления командами, оценками
и рейтингом: API-эндпоинты, проверку входных данных и тесты бизнес-логики.
Также участвовала в доработке интерфейса проекта

### [pixel](https://github.com/polisha067/pixel) · бэкенд и AI

Система обработки обращений клиентов банка. Она определяет тему
входящего письма, направляет его сотруднику и помогает подготовить
ответ с использованием языковой модели и базы знаний

Работала над серверной частью обработки писем и интеграцией AI:
поиском информации в базе знаний (RAG), использованием истории
переписки, генерацией и повторной генерацией ответов, а также
обработкой бизнес-информации из писем

### [GOsapiens](https://github.com/kmradished/GOsapiens) · Go

Командный проект с логикой поиска пользователей по общим интересам
и формирования взаимных совпадений

Работаю над модулеи подбора кандидатов по общим интересам: бизнес-правила,
сервисный слой, источник данных в памяти и модульные тесты
